# agent-toolkit

`agent-toolkit` is a small instruction repository for shared Codex working rules and skills.

It contains the shared instruction file in [`AGENTS.md`](./AGENTS.md), conventions for daily agent work, and skill definitions under [`skills/`](./skills/).

## What this repo is for

- Keep shared agent instructions in one place.
- Keep shared skills in one place.
- Provide a lightweight reference for the conventions used across related repositories.
- Avoid duplicating policy in individual project repos when the same rule applies broadly.

## Current rules covered

- SCSS, JSX, and TypeScript style guidance
- Functional programming rules for shared code
- Shared Codex skills for common workflows
- Git safety and remote-write restrictions
- Jira access, latest-ticket context, and mutation safety
- MongoDB database restrictions

## Notes

- This repository currently has no application code.
- `AGENTS.md` is the authoritative rule file for shared working conventions.
